O que aprendemos?

HTML5

Hierarquia de títulos utilizando as tags <h1> até <h6> para criar uma estrutura lógica e semântica no documento.

Parágrafos utilizando as tag <p> e </p> onde pode acrescentar símbolos como:
© ® ™ € £ ¥ ¢ ↑ ↓ com o comando &nome_do_símbolo.

Utilizar o <br> para quebrar a linha. Como por exemplo:
Esta é a primeira linha.
Esta é a segunda linha.

Principais formatações de textos

Negrito utilizando a tag <strong> e </strong>. Exemplo: Este é um texto em negrito.

Itálico utilizando a tag <em> e </em>. Exemplo: Este é um texto em itálico.

Riscado utilizando a tag <del> e </del>. Exemplo: Este é um texto riscado.

Subscrito utilizando a tag <sub> e </sub>. Exemplo: H2O.

Sobrescrito utilizando a tag <sup> e </sup>. Exemplo: 25.

Marcado utilizando a tag <mark> e </mark>. Exemplo: Este é um texto marcado.

Inserido utilizando a tag <ins> e </ins>. Exemplo: Este é um texto inserido.

Abreviações utilizando a tag <abbr> e </abbr>. Exemplo: HTML ou CSS.
