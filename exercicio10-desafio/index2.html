Imagens e links

A importancia do tamanho de uma imagem em HTML5 é fundamental para garantir uma boa experiência do usuário e otimizar o desempenho da página. Utilizando a tag <img> e o atributo <alt> que especifica o texto alternativo da imagem.

As duas imagens mostram o mesmo pinguim, mas em tamanhos diferentes. A primeira é a imagem completa com tamanho de 2.185 KB, enquanto a segunda é uma versão reduzida com tamanho de 16 KB. Isso pode afetar o tempo de carregamento da página e a performance do site.

Links utilizando a tag <a> e os atributos href="URL" e target="_blank". O atributo href especifica o destino do link, enquanto o atributo target define onde o link será aberto. Por exemplo, este link abrirá o Google em uma nova aba.

Listas

Listas não ordenadas utilizando a tag <ul> e </ul>. Cada item da lista é representado pela tag <li> e </li>. Exemplo:

  • Item 1
  • Item 2
  • Item 3

Listas ordenadas utilizando a tag <ol> e </ol>. Cada item da lista é representado pela tag <li> e </li>. Exemplo:

  1. Item 1
  2. Item 2
  3. Item 3
