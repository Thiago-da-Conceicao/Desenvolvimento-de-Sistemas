Usando links externos

Você pode acessar o meu repositório público no GitHub.

Utilizando a tag <a> com o atributo href: "URL" para criar links externos onde sobre o seu conteúdo

Você também pode acessar o canal do Curso em Vídeo para aprender HTML e CSS.

Nesse caso, o link será aberto em uma nova aba do navegador. Utilizando a tag <a> com os atributos target="_blank" e rel="external"
