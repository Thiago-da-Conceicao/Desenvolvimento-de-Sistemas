Principais formatações de textos

Negrito / Destaque

Nesta frase temos um termo em negrito usando a tag <b> (não semântica) e um termo em destaque usando a tag <strong> (semântica).

Itálico

Nesta frase temos um termo em itálico usando a tag <i> (não semântica) e um termo em ênfase usando a tag <em> (semântica).

Texto marcado

Podemor criar também um texto marcado usando a tag <mark>

Texto grande e pequeno

Podemos criar um texto grande utilizando a tag <big> (cujo estilo é obsoleto) e um texto pequeno utilizando a tag <small>.

Texto deletado

Podemos marcar um texto como excluido para indicar que ele não é mais válido, utilizando a tag <del>.

Texto inserido

Podemos marcar um texto como inserido para dar ênfase a uma informação nova, utilizando a tag <ins>.

Texto sobrescrito

Para inserir coisas do tipo x20+3 utilizando a tag <sup>

Texto subscrito

Para inserir coisas do tipo H2O utilizando a tag <sub>
