Utilizando as aspas duplas, a citação é feita com a tag <q>.

Citação completa

O computador é uma ferramenta poderosa que pode ser usada para resolver problemas complexos e facilitar a vida das pessoas.

Utilizando a tag <blockquote>, é possível criar uma citação completa, que pode incluir o autor e a fonte da citação.
